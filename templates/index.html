Architecture

Dual-Ensemble Machine Learning Pipeline

The prediction engine utilizes a high-performance ensemble of Random Forest Classifiers and Gradient Boosting Machines (GBM). Feature weights are learned from multi-dimensional student performance vectors covering academics, competitive coding, aptitude, practical software engineering portfolio, and industry internships.

1
Feature Ingestion & Encoding CGPA, DSA, Aptitude, Soft skills, One-Hot encoded branch vectors
2
Ensemble Soft Voting Weighted probability fusion: 0.55 * P(RF) + 0.45 * P(GBM)
3
Secondary CTC Multi-Tier Model Multi-class package tier prediction (Tier 3 through Super Dream)
4
Explainability & Gap Diagnostics Dynamic feature contribution and personalized action roadmap generation
